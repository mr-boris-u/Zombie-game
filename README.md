## 🧭 About the Project

**Zombie Survival HQ** is an interactive survival gaming platform built for fans of post-apocalyptic adventures. Players create a survivor, gather weapons and supplies, explore dangerous territories and take on survival missions. This repository contains a playable browser version of the game that runs on your own computer.

Every choice matters: manage your resources carefully, learn what you're up against and work with other survivors to push back the undead. The ultimate goal? **Survive the apocalypse and rebuild civilization!**

## ✨ Features

| Feature | Description |
| --- | --- |
| 👤 **Survivor Profiles** | Create a survivor with a name and a starting skill (Medic, Scavenger or Fighter) |
| 🎒 **Inventory Management** | Manage food, water, medicine, ammunition, crafting materials and barricades |
| 🗺️ **Interactive Maps** | Choose between four territories, each with its own danger level, supplies and threats |
| 🧟 **Zombie Database** | Unlock entries for five zombie types, with their behaviour and weaknesses |
| 🔨 **Crafting Guides** | Turn scavenged materials into medkits, barricades and ammo packs |
| 🎯 **Survival Missions** | Complete a mission in each territory to earn bonus experience |
| 🏆 **Leaderboards** | Track the top five survivor scores on your device |
| 🤝 **Multiplayer Challenges** | *Coming soon:* team up with or compete against other survivors |

## 🚀 Getting Started

### Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (LTS version recommended)
- A modern web browser

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mr-boris-u/VCC_3.git
   ```
2. Move into the project folder:
   ```bash
   cd VCC_3
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open `http://localhost:3000` in your browser.

For detailed setup instructions and troubleshooting, see the [Installation](https://github.com/mr-boris-u/VCC_3/wiki/Installation) page in the wiki.

## 🎮 Usage

1. **Create your survivor:** enter a name and choose a starting skill.
2. **Pick a territory:** open the Map and choose where to spend the day, or rest in your shelter.
3. **Survive encounters:** when a zombie appears, choose to fight, sneak past or run.
4. **Manage supplies:** craft medkits, barricades and ammo, and use medicine when your health is low.
5. **Last 10 days:** survive to reach the rebuilding camp, then see your score on the leaderboard.

Full gameplay instructions are on the [Usage](https://github.com/mr-boris-u/VCC_3/wiki/Usage) page in the wiki.
